# CG 数字产品实验室

> 把一个业务想法，变成客户看得懂、团队用得上、市场推得动的数字产品。

这是一个面向项目合作与方案推广的数字产品作品集，集中展示 AI 应用、产业互联网、社区服务、运动娱乐、循环经济和零售商业等领域的成熟产品思路。

这里展示的不只是几张界面，而是从用户角色、业务流程、交易履约到运营增长的完整产品闭环。无论你准备启动一个新项目、升级现有系统，还是希望把 AI 真正接入业务，都能在这里找到可快速落地的参考方案。

## 为什么值得继续看

- **更快验证想法**：已有清晰的产品框架与核心流程，可减少从零摸索的成本。
- **更容易推向市场**：兼顾用户体验、商业模式与运营能力，让产品不止“能用”，更有机会“好卖”。
- **更贴近真实业务**：覆盖小程序、PC 工作台、管理后台及多角色协同，关键状态形成闭环。
- **更适合持续成长**：方案可按行业、品牌和业务阶段灵活定制，为后续迭代预留空间。

## 精选系统方案

### 摊趣云 · 地摊租售平台

把场地、设备、商品和玩具租赁装进一个平台，支持预订、移动借还、费用结算和信用评价。适合城市便民服务、夜经济、共享设备及灵活经营项目，让闲置资源真正流动起来。

### 星桌云 · 台球数字经营系统

从在线订台、开台计费，到陪练约局、赛事会员和商品零售，一套系统串起台球门店经营全链路。帮助俱乐部提升球桌周转率、会员复购率和门店运营效率。

### 戎邻生活 · 退役军人社区服务平台

连接退役军人、社区、商户与公共服务资源，提供身份认证、政策触达、活动报名和权益服务。它不只是信息平台，更是一座有温度、能共建的数字社区。

### 搭界 · 组局活动系统

为兴趣社交和本地活动提供便捷的发起、匹配、报名、支付、核销与评价能力。普通用户轻松找到同好，主理人高效经营活动，平台则能沉淀可信、活跃的本地社群。

### 芯循宝 · 数码回收服务平台

围绕内存条、硬盘等数码设备，建立智能估价、寄送质检、隐私擦除和环保溯源流程。用透明的价格与可追踪的服务，解决用户在回收时最在意的信任问题。

### 寰智引擎 · 实体产业 AI 增长平台

把企业知识、营销内容、客户线索与 AI Agent 连接起来，让 AI 从“会回答”升级为“能执行”。适合希望提升内容生产、客户跟进和增长复盘效率的实体企业。

### 闪送运动 · 运动服务平台

聚合场馆、教练、课程、活动与运动搭子，为用户提供从发现服务到训练成长的一站式入口。帮助运动机构拓宽获客渠道，也让用户更容易坚持运动、持续消费。

### 安筑家 · 可信家装服务平台

通过资金托管、节点验收、材料透明和施工留痕，让业主、设计师、工长与材料商在同一套规则下协作。让装修进度看得见、费用说得清、问题追得到。

### 工业设备云管平台

覆盖设备接入、资产管理、远程运维、告警联动与数据驾驶舱，为工业现场建立统一的数字底座。支持主流工业协议与万级设备接入，让设备状态随时可见、异常响应更加及时。

### 微信商城与会员中台

融合商品交易、订单履约、会员等级、积分储值与营销活动，帮助实体商家快速建立自己的私域经营阵地。一次成交只是开始，持续复购和客户价值增长才是目标。

### 智聘云 · AI 招聘与人才协同平台

贯通职位发布、简历解析、人才匹配、面试协同和 Offer 管理，用 AI 辅助团队更快识别合适人才。招聘过程更清晰，协作更顺畅，数据也能真正帮助决策。

### 企业级 RAG 智能知识库

将散落在 PDF、制度、标准和业务文档中的知识，转化为可检索、可引用、可追溯的智能问答能力。适合企业知识查询、员工助手、客服支持与专业资料检索等场景，让答案不仅更快，而且有据可查。

## 本地运行

需要 Node.js 22 或更高版本：

```bash
npm install
npm run dev
```

生产构建与预览：

```bash
npm run build
npm run preview
```

## GitHub Pages 自动部署

项目已包含 `.github/workflows/deploy-pages.yml`。代码推送到 `main` 或 `master` 分支后，将自动构建并发布。

首次发布需要完成以下设置：

1. 打开仓库的 `Settings` → `Pages`。
2. 在 `Build and deployment` 的 `Source` 中选择 `GitHub Actions`。
3. 推送代码并打开 `Actions`，等待 `Deploy GitHub Pages` 执行成功。
